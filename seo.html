Search engine optimisation

Help people find
the right page.

SEO is part of looking after a website. I can review an existing site or include the initial setup in a new build.

  • Give each page a useful title and a clear description of the service it covers.
  • Check that search engines can access the pages, and fix broken links or missing information.
  • Review loading speed, image sizes and how the site works on a phone.
  • Check local business details and use Google Search Console to see how people find the site.

For ongoing SEO work, we'll agree on the changes and reporting you need. Search rankings depend on several factors, so I don't guarantee a particular position.
